# verify-visual (한글판)

그림에 대한 말은 그 뒤에 있는 측정만큼만 믿을 수 있다. 영어본: `SKILL.md`.

## 순서

1. **같은 크기로 렌더한다.** 비교할 두 쪽을 같은 픽셀 크기로. PowerPoint 내보내기,
   `pymupdf`의 `get_pixmap`, 헤드리스 브라우저 캡처 중 무엇이든.
2. **보기 전에 잰다.** 구역별 잉크 비율은 눈이 놓치는 것을 잡는다.

```python
c = img.convert("L").crop(box)
ink = sum(1 for v in c.getdata() if v < 110) / (c.width * c.height) * 100
```

   같은 구역을 전후로 비교한다. 크기만 바뀐 작업이면 사분면별 잉크 비율이 0.1%p 안에서 같다.
3. **가장자리를 본다.** 인쇄물은 바깥 10mm 안의 어두운 픽셀을 센다. 거기 글자가 있으면
   잘린다. 끝까지 채운 색 띠만 정상이다.
4. **그다음 한 번 본다.** 바꾼 부분만 잘라서 본다. 한 번 보고 한 번 고친다. 캡처를 반복하는
   고리를 만들지 않는다.

## 같이 확인할 사실

- 쪽수와 mm 크기(`rect.width * 25.4 / 72`)
- 내장 글꼴 수, 이미지 수
- 글자 추출 결과에 있어야 할 문구와 없어야 할 문구(옛 이름이 남아 있지 않은지)

## 규칙

- "괜찮아 보인다"는 결과가 아니다. 크기·개수·여백을 숫자로 말한다.
- 이번에 직접 렌더하지 않은 파일을 판정하지 않는다.
- 확인용 이미지는 결과물 폴더에 두지 말고 끝나면 지운다.
- 검사가 실패하면 고치고 다시 잰다. 설명으로 넘기지 않는다.
