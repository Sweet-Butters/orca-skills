# bilingual-repo (한글판)

영어는 처음 보는 사람과 검색이 먼저 읽고, 한글은 주인이 가장 빨리 읽는다. 둘 다 올린다.
영어본: `SKILL.md`.

## 구성

```
README.md                   # 영어, 기준
README.ko.md                # 한글판
skills/<이름>/SKILL.md      # 영어, 기준 — 도구가 읽는 파일
skills/<이름>/SKILL.ko.md   # 한글판
```

기준 파일이 도구가 읽는 frontmatter를 가진다. 한글판은 번역이지 갈라진 판이 아니다.
같은 절, 같은 순서, 같은 명령.

## 규칙

1. **기본 파일 이름은 영어가 가진다** — `SKILL.md`, `README.md`. 도구가 자동으로 찾는
   파일이 영어여야 언어 설정에 기대지 않는다.
2. **한 커밋에서 둘 다 고친다.** 어긋난 한글판은 없느니만 못하다. 하나만 고칠 상황이면
   영어를 고치고 한글판이 낡았다고 커밋에 적는다.
3. **서로 링크한다.** 각 파일 첫 세 줄 안에 "영어본: `SKILL.md`" / "Korean version:
   `SKILL.ko.md`".
4. **명령과 경로는 두 언어가 같다.** 설명만 번역하고 플래그·파일명·코드는 그대로 둔다.
5. **대답은 사용자가 쓴 언어로** 한다. 어느 파일이 불렸든 상관없다.
6. **frontmatter의 `description`은 영어로 쓰되 두 언어의 호출 문구를 모두 넣는다.**
   그래야 어느 말로 불러도 뜬다.
7. 스킬 이름은 소문자·숫자·하이픈만. 도구의 요구 사항이다.

## 올리기 전에

- 비밀번호·토큰·고객 이름·개인 이메일·집 경로가 없는지 본다.
- 범용 스킬에 특정 프로젝트 내용이 섞이지 않았는지 본다. 패턴만 적고, 어디서 썼는지는 적지 않는다.
- 공개 저장소는 영원히 공개다. 비공개 주제를 공개로 올리기 전에 반드시 묻고, 애매하면 비공개로 둔다.
