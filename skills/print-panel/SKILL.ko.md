# print-panel (한글판)

결과물은 항상 둘이다. **인쇄소에 줄 PDF**와 **문구를 고칠 PPTX**. 영어본: `SKILL.md`.

큰 판넬을 워드로 만들면 크기가 틀어지고 글꼴이 바뀐다. HTML로 만들고, 브라우저로 PDF를
뽑고, 잰 위치로 PPTX를 만든다.

## 1. HTML은 종이 크기 기준으로

```css
@page { size: A3 portrait; margin: 0; }
.frame { container-type: inline-size; }         /* 모든 치수를 cqw로 */
.sheet { width: 100%; height: 141.43cqw; }      /* 420/297 — A2와 같은 비율 */
```

컨테이너 단위를 쓰면 한 파일로 어느 크기든 인쇄된다. A2와 A3는 1:√2로 비율이 같아 그대로
확대·축소된다.

## 2. 인쇄용 PDF 내보내기

```python
page.pdf(path=..., width="297mm", height="420mm", print_background=True,
         margin={"top": "0", "right": "0", "bottom": "0", "left": "0"},
         prefer_css_page_size=True)
```

**한 쪽**인지, mm 크기가 맞는지, 가장자리 10mm 안에 글자가 없는지 확인한다(`verify-visual`).

## 3. 잰 위치로 PPTX 만들기

렌더된 화면에서 요소 위치를 시트 기준 단위로 재고, `python-pptx`로 도형·글상자를 다시 만든다.

- 슬라이드 크기 = 종이 크기(mm).
- 어느 컴퓨터에나 있는 글꼴만 쓴다(Arial·Arial Black, OS 한글 글꼴, 고정폭). 웹 글꼴은 남의
  PowerPoint에서 살아남지 않는다.
- 바뀐 글꼴은 폭이 넓다. PIL로 재서 줄바꿈 대신 크기를 줄인다.
- 작은 벡터 마크(아이콘·로고 조합)는 캡처해서 그림으로 넣는다.
- 고치는 방법은 발표자 노트에 적는다.

## 4. 로고는 자리만 두고 파일로 받는다

점선 칸을 두고 사용자가 준 파일로 채운다. 기관 로고를 직접 그리거나 비슷하게 만들지 않는다.
투명 PNG는 흰 배경에 합성한 뒤 넣는다. 안 그러면 투명 부분이 검게 인쇄된다. 그 로고를 써도
되는지 사용자에게 확인한다.

## 5. 다시 인쇄하지 않아도 되는 QR

QR에는 **우리가 바꿀 수 있는 고정 주소**를 넣고 그 주소가 실제 목적지로 넘기게 한다
(`/survey` → 폼). 목적지가 바뀌어도 한 줄만 고치면 되고 인쇄물은 그대로다. QR 크기는 읽는
거리의 약 1/10 — 1m에서 찍으려면 A3에 약 10cm.

## 6. 크기 바꾸기

위치·크기·글자 크기·선 두께를 같은 비율로 곱하고(A2→A3는 297/420) 다시 내보낸 뒤, 원본과
구역별 잉크 비율을 비교한다. 두 파일 다 남긴다.

## 규칙

- 결과물은 git 밖에 두고, 사용자가 고친 파일을 덮어쓰기 전에 백업한다.
- 사용자가 손으로 고친 파일 위에 다시 생성하지 않는다. 새 이름으로 낸다.
- 쪽수·크기·여백을 느낌이 아니라 숫자로 보고한다.
