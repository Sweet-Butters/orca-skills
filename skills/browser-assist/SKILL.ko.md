# browser-assist (한글판)

어떤 일은 남의 계정 로그인 뒤에 있고 API가 없다. 안전하게 나누는 기준은 하나다.
**신원은 사용자가, 클릭은 에이전트가.** 영어본: `SKILL.md`.

## 역할 나누기

| 사용자가 하는 것 | 에이전트가 하는 것 |
|---|---|
| 로그인 | 화면 열기, 읽기, 설정 눌러 바꾸기 |
| 권한·동의 창 누르기 | 양식 채우기, 준비한 내용 붙여넣기, 결과 읽기 |
| 무엇을 공개할지 결정 | 무엇이 바뀌었는지 보고, 바깥에서 확인 |

비밀번호는 묻지도, 입력하지도, 저장하지도 않는다. 계정 접근 권한을 주는 동의 화면은 누르지
않는다. 그것은 사용자의 몫이다.

## 진행 방식

내장 브라우저(Orca 브라우저·Playwright·CDP)를 스냅샷 → 조작 → 다시 스냅샷으로 다룬다.

```text
tab list                      # 사용자가 이미 연 탭 찾기
snapshot                      # 요소 참조는 탭마다 다르고 이동하면 무효
click --element @e34
wait --text "..."             # 고정 시간 대기 대신
snapshot                      # 클릭 전 참조는 이미 무효
```

새 탭을 만들기보다 사용자가 열어 둔 탭을 쓴다. 누른 버튼 이름을 그대로 보고해 사용자가
되짚을 수 있게 한다.

## 긴 내용은 타자 대신 편집기에 넣는다

편집기가 있는 화면이면 수천 자를 타자로 치지 말고 값을 직접 넣는다.

```javascript
monaco.editor.getModels()[0].setValue(<JSON으로 인코딩한 문자열>)
```

그리고 들어갔다는 증거를 읽는다. 줄 수, 함수 이름, 길이 같은 것.

## 확인은 로그인 밖에서

그 화면이 멀쩡해 보이는 건 **내가 로그인해서**다. 남이 보는 대로 확인한다. 로그인하지 않은
상태로 공개 주소를 받아 상태 코드·이동·내용을 확인한다. "게시됨" 표시는 증거가 아니다.

## 규칙

- 계정 설정을 바꾸기 전에 무엇을 바꾸는지 먼저 말한다.
- 돈이 나가거나, 남에게 메일이 가거나, 공개 범위가 바뀌는 일은 멈추고 묻는다.
- 화면이 이동하면 스냅샷을 다시 뜬다. 낡은 참조는 엉뚱한 것을 누른다.
- 사이트가 자동화를 막으면 그렇다고 말하고, 대신 누를 순서를 짧게 알려 준다.
